# DWM3000 UWB 펌웨어

이 폴더에는 **로봇 앵커 2개 + 사람이 들고 다니는 태그 1개** 구성용 코드가
있습니다. UWB 장치는 앵커와 태그 사이의 **거리만** 측정합니다. 사람의 위치
계산은 젯슨이 합니다.

```text
왼쪽 앵커 ─ 태그까지 거리 ─┐
                            ├─ 젯슨: 사람의 좌우 / 전방 위치 계산
오른쪽 앵커 ─ 태그까지 거리 ┘
```

앵커는 태그에 Poll 신호를 보내고, 태그가 타임스탬프를 포함한 응답을 보냅니다.
각 앵커는 왕복 시간을 자기 거리로 변환해 USB로 출력합니다. 젯슨의
`ai_vision/uwb_comm.py`는 두 USB 출력과 앵커 간격을 이용해 위치를 계산합니다.

## 업로드 전 확인

이 코드는 사용자가 보내준 기존 태그 코드와 같은 `dw3000.h` 라이브러리를
사용합니다. `spiBegin()`과 `spiSelect()`를 쓰므로 DW1000 라이브러리로 바꾸면
안 됩니다.

- Arduino IDE에서 기존 태그 코드를 컴파일했던 보드 종류와 라이브러리를 그대로 선택합니다.
- 세 보드는 `RST=5`, `IRQ=4`, `SPI SCK=21`, `MISO=22`, `MOSI=23`을 씁니다.
  단, 왼쪽 앵커만 `SS=2`이고 오른쪽 앵커와 태그는 `SS=20`입니다.
- 배선이 다르면 각 `.ino` 파일 맨 위의 핀 번호를 실제 배선에 맞게 바꿉니다.

## 업로드 순서

1. `uwb/tag/tag.ino`를 사람이 들고 다닐 태그에 업로드합니다.
2. `uwb/anchor_left/anchor_left.ino`를 로봇의 **왼쪽**에 붙일 앵커에 업로드합니다.
3. `uwb/anchor_right/anchor_right.ino`를 로봇의 **오른쪽**에 붙일 앵커에 업로드합니다.
4. 왼쪽과 오른쪽 앵커를 젯슨 USB에 각각 연결합니다.
5. 터미널에서 `ls /dev/ttyACM*`를 실행해 포트를 확인한 뒤,
   `ai_vision/config.py`의 `UWB_LEFT_PORT`, `UWB_RIGHT_PORT`에 적습니다.
6. 아래의 앵커 간 중심거리를 측정해 `UWB_ANCHOR_BASELINE_M`에 적습니다.

태그는 사용 중에는 보조배터리 같은 이동식 전원만 연결하면 됩니다. 태그 USB를
젯슨에 연결할 필요는 없습니다.

## 앵커 간 중심거리 설정

`UWB_ANCHOR_BASELINE_M`은 로봇의 왼쪽 앵커와 오른쪽 앵커에 있는 **UWB 안테나
모듈의 가운데 점끼리의 거리**를 미터 단위로 적는 값입니다.

```text
왼쪽 앵커 모듈 중심 ● <──── 실제 측정 거리 ────> ● 오른쪽 앵커 모듈 중심
                    예: 30cm 이면 config에는 0.30
```

자로 앵커 케이스의 한쪽 끝이 아니라, 가능하면 안테나가 있는 모듈의 중앙끼리
재세요. 두 앵커를 30cm 간격으로 붙였다면 다음처럼 둡니다.

```python
UWB_ANCHOR_BASELINE_M = 0.30
```

## 정상 출력 확인

태그 전원이 켜진 상태에서 앵커를 젯슨에 연결하면, 각 앵커는 아래처럼 한 줄씩
거리 데이터를 출력합니다.

```text
ANCHOR2,1.234
```

두 앵커가 모두 이 값을 계속 출력하면 웹 화면에서 `UWB 앵커`는 `좌/우 연결`로,
`UWB 태그 위치`는 `좌우 / 전방 m` 형식으로 표시됩니다.

## 보정

현재 RX/TX 안테나 지연값 `16385`는 보내준 기존 태그 코드 값을 사용합니다.
실제 거리를 줄자로 재어 보고 오차가 크면, 사용하는 DWM3000 보드의 안테나 지연
보정 방법에 따라 세 장치의 값을 보정해야 합니다.
