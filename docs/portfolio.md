# 포트폴리오용 프로젝트 기록

## 대회 프로젝트

**사용자 위치 인식 기반 자율주행 카트 시스템**은 제9회 AI ROBOTICS 융합 아이디어 경진대회에서 제작한 팀 프로젝트다. 최종 발표자료(2026-06-23) 6쪽에는 Jetson Orin Nano, Logitech C920, ESP32, 메카넘 휠 플랫폼 구성과 사용자 등록부터 모터 구동까지의 흐름이 기록되어 있다. 7–8쪽에는 TensorRT 추론, EMA, 데드존과 히스테리시스 적용 과정이, 9쪽에는 UWB–Jetson 연동이 대회 기간 내 미완성이었다는 기록이 남아 있다.

## 대회 이후 보완

- **주행 정지 조건**을 보완했다. 영상이 끊겨도 마지막 검출이 남아 전진 명령을 반복하던 문제를 찾았다. 카메라 프레임과 제어 명령에 유효 기간을 두고, ACK 확인과 운영자 활성화가 있어야 추종하도록 했다.
- **UWB 수신과 좌표 계산**을 검증했다. 동일한 수신 코드에 두 가상 앵커의 거리 로그를 공급했다. 좌측 1.300m, 우측 1.217m, 앵커 간격 0.30m에서 태그 위치는 우측 약 0.35m, 전방 약 1.20m였다. 분할 수신, 한쪽 측정 만료, 포트 ID 뒤바뀜과 재연결도 검사했다. 별도의 C++ 모의 장치에서는 앵커의 Poll과 태그 응답을 연결해 거리 계산과 시퀀스 검사, 응답 타임아웃을 확인했다.
- **모터 인터페이스**의 재사용 정보를 남겼다. 대회 카트에서 실측한 74HC595 비트를 바퀴와 회전 방향으로 이름 붙였다. 이식할 때 바꿀 GPIO와 enable 극성, 단일 비트 점검 모드, 기존 명령별 출력값을 문서화했다.

## 검증 범위

가상 직렬 환경은 Jetson 쪽의 거리 파싱과 상태 변화 및 모터 ACK 처리를 검증한다. C++ 모의 장치는 펌웨어의 상태 전이와 계산을 검증한다. 실제 보드의 UWB 무선 링크, 거리 오차, 가림 환경의 사람 재인식, 카트 정지거리는 장비 시험 항목이다.

1차 보완의 Windows 검증에서는 Python 테스트 15개와 모터·UWB C++ 모의 시험 2개가 통과했다. Arduino CLI 1.3.1과 ESP32 코어 2.0.17에서 모터 스케치는 ESP32, UWB 스케치 3개는 ESP32-S3 타깃으로 컴파일했다.

## 소개 문장 예시

> Jetson Orin Nano에서 실시간 사람 검출을 수행하고 ESP32로 모터를 제어하는 사용자 추종 카트를 팀으로 제작했습니다. 대회 이후 추론이 중단됐을 때 남은 주행 명령을 차단하도록 제어 흐름을 개선했습니다. UWB는 가상 앵커 두 개로 거리 수신과 좌표 계산, 통신 중단 후 복구를 검증했으며, 실측한 모터 비트 매핑을 다른 차체에 옮길 수 있도록 정리했습니다.

## UWB 주행 통합 검증

후속 버전에서는 UWB 좌표가 ESP32의 전진·회전·정지 마스크로 이어지게 했다. 좌우 가상 앵커와 실제 Arduino 스케치의 모의 실행을 연동해 출력을 확인했다. 별도의 폐루프 차체 모델에서는 왼쪽과 오른쪽에서 출발한 경우 모두 15.40초에 태그와 약 0.82m 떨어진 위치에 정지했다. 최신 Windows 검증에서 Python 테스트 22개와 C++ 모의 시험 2개가 통과했으며 Linux 전용 PTY 테스트 1개는 제외했다. 시뮬레이션 조건과 보드 연결 절차는 [UWB 통합 가이드](uwb_drive.md)에 있다.
